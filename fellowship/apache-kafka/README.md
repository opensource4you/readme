# Apache Kafka 組的提名說明

提名的前提只有一個：**你要在 Kafka repo 上夠活躍，或是有特殊貢獻。**

格式和流程請看上一層的 [README](../README.md)，範例請看 [chia7712.md](./chia7712.md)。

## 夠活躍

兩種方式，後者比較重：

- 提交 PR
- 做好的 review

Review 比 PR 重，因為 review 是 Kafka 社群最缺的東西，也是通往 committer 的路。好的 review 指的是真的看懂了改動、指出問題、幫作者把 PR 推到可以合併，不是留一個 LGTM。可以參考[review 的重要性](https://www.facebook.com/share/p/19bCy4hH47/)。

## 特殊貢獻

目前有兩種：

- 協助推廣開源，例如對外演講、寫文章、帶活動
- 協助撰寫教材

這兩種不要求同時在 repo 上活躍，但事蹟一樣要附連結。

## 寫法提醒

- 事蹟用「做了什麼」來寫，每條附連結。PR 和 review 可以直接用 GitHub search URL，例如 `https://github.com/apache/kafka/pulls?q=is%3Apr+reviewed-by%3A<github-id>+updated%3A%3E%3D2026-09-01`。
- Review 請挑幾個有份量的直接貼連結，比只寫數量有說服力。
