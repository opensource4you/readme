## Kafka

### 作業

跑起來的證明：

```
$ bin/kafka-server-start.sh config/server.properties
[KafkaRaftServer nodeId=1] Kafka Server started
$ bin/kafka-topics.sh --create --topic test --bootstrap-server localhost:9092
Created topic test.
```

專案在解什麼：
分散式的 log，讓很多 producer 寫、很多 consumer 讀，資料按 partition 排序並複製到多台機器，broker 掛了資料不會掉。

看了哪塊程式碼：
`clients/src/main/java/org/apache/kafka/clients/producer/internals/RecordAccumulator.java`。producer 送出的 record 先進這裡依 partition 排隊，湊滿 `batch.size` 或等到 `linger.ms` 才真的送出。從 `KafkaProducer#doSend` 一路追進來的。
