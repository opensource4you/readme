# 參與開源社群應有的心態

- 作者：Tingyao Huang
- 背景：近期陸續有新成員加入 YuniKorn 社群，藉此再次提醒大家幾件事。這些提醒不限於 YuniKorn，參與任何開源社群都適用。

## 盡量讓討論公開透明

不論是有問題想請教，或是需要協助，都建議在公開頻道進行。你遇到的問題，很可能也是其他人會遇到的問題，公開討論能讓更多人受益，也方便日後查找。

## 貢獻的形式很多元

接 issue、送 PR、寫 code 固然是貢獻，但 review 別人的 PR、回答問題、參與討論同樣也是相當有價值的貢獻方式，鼓勵大家多方參與。

## 留意自己手上的 issue 狀態

請定期關注自己手上還有多少 issue 處於 open 或 in progress 狀態。如果有過多尚未動工的 open issue，建議適時釋出，讓有意願的人接手；至於 in progress 中已有 PR 待 review 的，也歡迎隨時貼到 Slack channel，讓大家一起協助檢視。

## 謹慎使用 AI 工具

善用 AI 確實能提升效率，但前提是你必須真正理解並掌握它產出的內容，能在出現幻覺或錯誤時即時指出。這需要你對專案有一定的了解，否則若只是全盤接受 AI 的輸出，就容易淪為橡皮圖章——這種情況在其他專案已有不少例子，還請大家多加留意。

## 重視測試驗證

這點嘉平也提過多次：你必須確認自己 PR 的 change 確實能解決問題，而驗證這件事最可靠的方式就是撰寫並執行測試。

## 信任是慢慢累積的

社群對新成員的信任需要時間培養。因此在社群成員還不熟悉你之前，請保持足夠的禮貌與耐心。前面提到的 PR 品質、review 品質，以及日常討論中的回覆，都是在一點一滴累積社群對你的認可。
